## 🚀 Quick Deployment (5 Minutes)

### Step 1: Prepare Your Data
1. Put your `tanzania_gdp_data.csv` file in the `data/` folder
2. Make sure it has these columns:
   - Year, Quarter, GDP_Billion_USD
   - Plus your economic indicator columns

### Step 2: Upload to GitHub

**Easy Way (No Terminal):**
1. Go to [github.com](https://github.com) → New repository
2. Name it `tanzania-gdp-predictor`
3. Make it Public
4. Upload ALL the files I created

**Terminal Way:**
```bash
cd tanzania-gdp-predictor
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/tanzania-gdp-predictor.git
git push -u origin main
```

### Step 3: Deploy to Streamlit
1. Go to [share.streamlit.io](https://share.streamlit.io)
2. Sign in with GitHub
3. Click "New app"
4. Select your repository
5. Set main file to `app.py`
6. Click "Deploy!"
7. Wait 2-5 minutes

**🎉 Done! Your app is live!**
